# המכבים · The Maccabees: playtest build

עבודה בתהליך. גרסת ניסוי מ-18 בנובמבר 2026 (מקור: קומיט dabfb67), לכמה חברים. עדיף דפדפן שולחני עם כרטיס גרפי אמיתי (Chrome או Edge). הטעינה הראשונה לוקחת דקות. החומר ההיסטורי במשחק מסומן ברמות ודאות ובסימון "השלמה דרמטית".
Work in progress: a playtest build of 18 Nov 2026 (source commit dabfb67), for a few friends. Best on a desktop browser with a real graphics card (Chrome or Edge); the first load takes minutes. The game's historical material is labelled with certainty levels and as dramatization.
